# Group Messenger Android Project

This repository contains the source code and resources for a legacy Android Group Messenger application.

## Project structure

- `gr-me-an/src/` — Java source files
- `gr-me-an/res/` — Android layouts, menus, and values
- `gr-me-an/AndroidManifest.xml` — application manifest
- `gr-me-an/bin/GroupMessenger.apk` — prebuilt APK included in the original archive

## Notes

This project uses the older Eclipse/Ant Android project format. Opening it in a recent Android Studio release may require migration. The messaging implementation is intended for an Android emulator test environment; it is not a production internet messaging service.
